# 🌐 NetScan-Lite: Lightweight Port Scanner

NetScan-Lite — это многопоточный сканер портов на языке Python, предназначенный для быстрого анализа открытых портов на целевом хосте и идентификации стандартных сетевых сервисов.

## 🚀 Функционал
- **Многопоточность:** Использование `threading` и `Queue` для одновременного сканирования множества портов, что значительно увеличивает скорость работы.
- **Идентификация сервисов:** Встроенный словарь наиболее популярных портов (SSH, HTTP, HTTPS, MySQL и др.).
- **DNS Resolution:** Возможность указать доменное имя вместо IP-адреса.

## 🛠 Технологии
- **Язык:** Python 3.x
- **Модули:** `socket` (сетевые соединения), `threading` (параллелизм), `queue` (управление задачами).

## 📦 Запуск
1. Клонируйте репозиторий:
```bash
   git clone https://github.com/[ваш_ник]/netscan-lite.git
   cd netscan-lite
```
2. Запустите программу:
```bash
   python scanner.py
```
