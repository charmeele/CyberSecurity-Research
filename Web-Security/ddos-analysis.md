# 🛡️ Анализ механизмов DDoS-атак и методов защиты

## 🎯 Цель исследования
Изучить теорию распределенных атак типа «отказ в обслуживании» (DDoS), классифицировать их по уровням модели OSI и определить наиболее эффективные методы противодействия.

## 🔍 Классификация атак

### 1. Сетевой и транспортный уровни (L3/L4)
Атаки направлены на исчерпание пропускной способности канала или ресурсов стека TCP/IP.
- **SYN-flood:** Эксплуатация TCP-рукопожатия. Создание большого количества «полуоткрытых» соединений.
- **UDP-flood:** Переполнение порта случайными UDP-пакетами, заставляющее сервер тратить ресурсы на ответы ICMP "Port Unreachable".

### 2. Уровень приложений (L7 - HTTP Flood)
Имитируют поведение реальных пользователей, что делает их сложными для обнаружения.
- **HTTP GET-flood:** Массовые запросы к тяжелым страницам сайта.
- **Slowloris:** Медленная передача HTTP-заголовков для удержания соединений открытыми максимально долго.

## 🛡️ Стратегии защиты (Mitigation)

| Метод | Описание | Эффективность |
| :--- | :--- | :--- |
| **Rate Limiting** | Ограничение количества запросов с одного IP | Высокая (против простых флудов) |
| **WAF (Web App Firewall)** | Анализ сигнатур и заголовков запросов | Высокая (против L7 атак) |
| **CDN / Anycast** | Распределение трафика по сети серверов (Cloudflare) | Максимальная (против L3/L4 и L7) |
| **TCP Syncookies** | Механизм защиты от SYN-флуда на уровне ядра ОС | Высокая (для L4) |

## 📝 Вывод
Для полноценной защиты системы надо в многослойный подход (Defense in Depth)
